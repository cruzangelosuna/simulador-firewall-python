# Simulador de Firewall en Python

## Descripción
Este proyecto es una simulación educativa de un firewall básico. Utiliza una lista negra de direcciones IP para decidir si una dirección de origen puede acceder a un servidor simulado.

## Objetivo
Comprender cómo funciona una regla sencilla de filtrado de red mediante una lista de control de acceso.

## Requisitos
- Python 3
- Programiz Online Compiler o una instalación local de Python

## Ejecución
1. Abre `simulador_firewall.py` en Programiz o en tu editor de Python.
2. Ejecuta el programa.
3. Escribe una dirección IP cuando el programa lo solicite.
4. Escribe `salir` para terminar.

## Direcciones IP bloqueadas de ejemplo
- `192.168.1.100`
- `10.0.0.25`
- `172.16.0.50`

Las demás entradas se muestran como permitidas en esta simulación.

## Archivos
- `simulador_firewall.py`: código fuente del simulador.
- `README.md`: documentación del proyecto.

## Limitaciones
Este programa es únicamente una demostración educativa. No captura tráfico real, no modifica la configuración de red y no sustituye a un firewall de producción.
